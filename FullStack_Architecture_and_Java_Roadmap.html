1. Root Cause: Why Did the Disconnect Happen?

+-------------------------------------------------------------------------+ | CLIENT (Frontend Browser) | | - HTML, CSS, JavaScript (React / Vite bundle) | | - Runs strictly inside the visitor's web browser | | - Does NOT have direct database access or file system access | +-------------------------------------------------------------------------+ | HTTP / REST Requests (fetch / axios) v +-------------------------------------------------------------------------+ | SERVER (Backend Host) | | - Node.js (Express) or Java (Spring Boot) | | - Manages database transactions, authentication, and business logic | | - Listens on a dedicated network port (e.g. 5000 or 8080) | +-------------------------------------------------------------------------+
  • Port 3000 was static-only: npx serve served HTML/CSS. When React requested /api/students, it returned index.html (causing JSON syntax errors).
  • Cloudflare pointed only to Port 3000: Port 5000 (Backend API & Database) was unreachable.
  • Unified Port 5000 Solution: Express on Port 5000 now serves the React build from / AND all REST APIs from /api/* on the same port!

2. How to Get a Constant / Permanent URL (No Random URLs)

When using cloudflared tunnel --url http://localhost:5000, Cloudflare generates a random temporary URL (Quick Tunnel). Here is how to get a constant, unchanging URL:

Method A: LocalTunnel with Fixed Subdomain (Instant & Zero Configuration)

Run the following command in PowerShell. It gives you the exact same URL every single time:

npx localtunnel --port 5000 --subdomain aegisedu-portal
Permanent URL: https://aegisedu-portal.loca.lt
Method B: Cloudflare Named Tunnel (Official Enterprise Method)
  1. Login: cloudflared tunnel login
  2. Create tunnel: cloudflared tunnel create aegis-prod
  3. Route to your domain or subdomain: cloudflared tunnel route dns aegis-prod portal.yourdomain.com
  4. Run: cloudflared tunnel run aegis-prod
Method C: Permanent Free Cloud Deployment (Render / Railway)

Deploy directly to Render or Railway. You get a permanent, 24/7 online URL (e.g., https://aegisedu.onrender.com) that never changes and doesn't require your laptop to be awake.

3. Where and How to View API Request Logs

You can monitor API activity in three different places:

  • 1. Live Terminal (Real-Time Console): In the terminal running npm start, every incoming request is logged live:
    ⚡ [18:55:12] GET /api/stats -> HTTP 200 (12ms)
    ⚡ [18:55:15] GET /api/students?page=1 -> HTTP 200 (8ms)
    ⚠️ [18:55:30] POST /api/auth/login -> HTTP 401 (4ms)
  • 2. In the Web Database Manager: Open http://localhost:5000/ → Click the Database tab → Open the audit_logs table to view system events and diagnostic records.
  • 3. Browser Developer Tools: Press F12 → Click the Network tab → Filter by Fetch/XHR to see live requests, response times, headers, and JSON payloads.

Auto-Recovery with Process Supervisors (PM2)

If your server crashes due to an unhandled exception or memory issue, a process supervisor restarts it in milliseconds so your tunnel stays alive:

npm install -g pm2
pm2 start server/server.js --name "aegisedu" --watch
pm2 logs aegisedu (View live logs)
